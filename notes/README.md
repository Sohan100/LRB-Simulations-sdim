# Notes

Where we think out loud about the project, so that one of us can post an idea and the other can
pick it up later with the full context. Code, results and the paper live in the rest of the
repository; this folder holds the conversation around them.

| folder or file | what goes there |
|---|---|
| `TODO.md` | open tasks, with an owner and a link to the thread or file they belong to |
| `meetings/` | one file per meeting, `YYYY-MM-DD-<who or topic>.md`; Granola notes can go in as they are |
| `discussions/` | one file per open question; reply at the bottom with the date and your name |

A discussion thread starts with the question and what we already know, with links into the repo.
Replies go underneath in order:

```markdown
## 2026-11-25, Chuanhong
...
```

When a thread reaches a decision, write the decision at the top of the file and tick the task in
`TODO.md`.
